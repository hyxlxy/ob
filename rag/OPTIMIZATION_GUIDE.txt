# RAG系统优化指南
# ==================

## 优化概览

本次优化基于RAG最佳实践，从离线索引和在线检索两个阶段进行了系统性改进。

## 一、离线索引阶段优化

### 1.1 文档分片优化 (src/split/split.py)
- 语义感知分片：按段落、标题边界切分，保持语义完整性
- 表格保护：自动检测Markdown表格，尽量保持表格完整
- 智能重叠：使用150字符重叠，保持上下文连续性

### 1.2 数据导入优化 (src/core/add.py)
- 数据存在检查：避免重复导入
- 动态并行度：根据PDF数量自动调整worker数
- VLM增强：对文字稀疏页面使用VLM提取视觉信息

## 二、在线检索阶段优化

### 2.1 Query预处理 (src/core/query_processor.py)

**问题类型识别**：
- time_fact: 时间事实类（成立时间、什么时候）
- numeric_fact: 数值事实类（营业收入、百分比）
- entity_fact: 实体事实类（产品类别）
- analysis: 分析性（如何、为什么）
- comparison: 对比性（与...相比）
- list: 列表类（有哪些）

**关键词提取**：
- 提取公司名、年份、百分比等数值
- 匹配预定义的财务术语（营业收入、毛利率等）

**HyDE假设性文档**：
- 使用LLM生成假设性答案
- 用假设性答案的embedding进行检索
- 提升query与文档表述的对齐度

### 2.2 多路检索策略 (src/core/search_optimized.py)

**三路并行检索**：
1. 原始查询向量检索
2. BM25全文检索
3. HyDE向量检索（可选）

**RRF融合**：
- 使用倒数排序融合合并多路结果
- 权重配置：向量检索1.2, HyDE 1.1, BM25 1.0

### 2.3 智能重排序 (src/core/reranker.py)

**文件级评分**（权重40%）：
- 文件名关键词匹配
- 报告类型权威性（深度报告 > 研究报告 > 公司报告）
- 时效性（年份越新分数越高）
- 问题类型加权

**Chunk级评分**（权重60%）：
- 关键词密度
- 语义相关性
- 信息完整性
- 数值类问题的精确度

### 2.4 来源定位优化 (search_optimized.py: pick_best_source)

**多策略来源选择**：
1. 数值覆盖率优先：答案中的数值在chunk中完全匹配
2. 关键词重叠度：答案与chunk的词汇重叠
3. 问题关键词匹配
4. 重排序得分加成

**邻页回溯**：
- 检查最佳匹配的前后页
- 处理跨页内容的情况

### 2.5 针对性Prompt (src/prompt/query.py)

**根据问题类型选择Prompt**：
- 数值类：强调数值准确、包含单位
- 列表类：列出所有项目、使用顿号分隔
- 分析类：条理清晰、分点说明

**答案后处理**：
- 移除冗余开头（"根据文档，"）
- 移除来源引用（系统自动处理）
- 确保格式简洁

## 三、配置参数

环境变量配置见 .env.example：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| TOP_K | 20 | 返回的最大结果数 |
| BM25_CANDIDATES | 80 | BM25检索候选数 |
| VEC_CANDIDATES | 120 | 向量检索候选数 |
| RRF_K | 60 | RRF融合常数 |
| MAX_CONTEXT_CHARS | 24000 | 上下文最大字符数 |
| ENABLE_HYDE | true | 是否启用HyDE |

## 四、评分优化策略

### 评分公式
总分 = 文件名匹配(25分) + 页面匹配(25分) + 答案相似度(50分)

### 优化重点
1. **页面匹配准确率**：通过智能重排序和多策略来源选择提升
2. **答案质量**：通过针对性Prompt和多路检索提升
3. **数值完整性**：强调数值准确，包含正确单位

## 六、预期效果

基于优化措施，预期达到的效果：
- 页面匹配准确率：85-90%
- 答案内容相似度：70-80%
- 综合得分：75-85分

## 七、注意事项

1. **时间限制**：40分钟内完成，需要控制并行度和API调用频率
2. **API限流**：动态调整延迟，避免触发限流
3. **HyDE开销**：HyDE会增加一次LLM调用，可通过ENABLE_HYDE=false关闭
4. **数据重建**：如需重建数据，可删除数据库表或使用force_rebuild参数
