def add(dataset_dir: str, max_worker: int):
    # 1. 扫描 PDF 文件
    pdf_files = glob.glob(os.path.join(dataset_dir, "*.pdf"))
    
    # 2. 初始化 OceanBase 客户端
    client = get_or_create_client()
    
    # 3. 探测嵌入维度并创建表
    vector_dim = _detect_embedding_dim()
    create_table_if_not_exists(client, vector_dim)
    
    # 4. 并行处理 PDF 文件
    with ThreadPoolExecutor(max_workers=max_worker) as executor:
        for pdf_file in pdf_files:
            executor.submit(process_pdf_file, pdf_file, client)
关键参数:

max_worker=8: 并行处理 PDF 的线程数

3.5 RRF 融合算法
Reciprocal Rank Fusion (RRF):

python
def _rrf_fuse(bm25: List[Dict], dense: List[Dict], top_k: int) -> List[Dict]:
    """
    RRF 公式: score(d) = Σ 1/(k + rank_i(d))
    其中 k = RRF_K = 60
    """
    scores: Dict[str, float] = defaultdict(float)
    
    # BM25 结果贡献分数
    for rank, doc in enumerate(bm25, start=1):
        scores[key(doc)] += 1.0 / (RRF_K + rank)
    
    # 向量结果贡献分数
    for rank, doc in enumerate(dense, start=1):
        scores[key(doc)] += 1.0 / (RRF_K + rank)
    
    # 按融合分数排序，取 top_k
    return sorted_by_score[:top_k]

七、当前问题与优化方向
7.1 来源选择问题 (高优先级)
问题: 只取 RRF 融合后第一条结果的 filename 和 page

影响: 即使检索到正确信息，如果不在第一位，来源就错

优化方案:

让 LLM 在回答中指明来源，解析 LLM 输出
答案生成后，计算答案与各 chunk 的相似度，选最相关的
多个 chunk 来自同一页时投票
7.2 检索召回问题 (中优先级)
问题: 正确答案可能未被召回

优化方案:

增大 TOP_K 和候选数
添加 Reranker 重排序
Query 改写/扩展
7.3 分块质量问题 (中优先级)
问题:

答案被切到两个 chunk
chunk 太大导致噪声
关键信息（如数字）被遗漏
优化方案:

按语义/标题边界分块
增加重叠
优化 VLM prompt 确保数值准确
7.4 VLM 触发策略 (低优先级)
问题: 500 字符阈值可能不够精准

优化方案:

降低阈值
结合页面是否有图片判断
对所有页面都用 VLM
